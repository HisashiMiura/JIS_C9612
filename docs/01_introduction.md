# はじめに

## 目的

本書は、JIS C 9612:2013 附属書 B に基づいて、回転数制御形ルームエアコンの通年エネルギー消費効率 (APF)を計算する方法と、その方法を実装した計算プログラムについて説明する。

本書の目的は、次の 2 つである。

1. 附属書 B の計算手順を、計算プログラムと 1 対 1 に対応する形で書き下し、計算結果を第三者が検証できるようにする。
2. 附属書 B の記述のうち、解釈が必要な箇所や明記がない事項について、本書が採った方法とその理由を記録する。

## 準拠する規格

本書は、次の規格に準拠する。

:::{container} symbols
JIS C 9612:2013
: ルームエアコンディショナ。2013 年 (平成 25 年)4 月 22 日改正
:::

このうち、附属書 B (規定)「ルームエアコンディショナの期間エネルギー消費効率算定のための試験及び算出方法」の算出方法を扱う。
本書では、この附属書を単に附属書 B と呼ぶ。

本書は、試験で得た値から APF を計算する部分だけを扱う。試験の方法と条件は、附属書 B と、そこで引用している規格による。
本書は規格の文章を転記していない。計算方法の確認には、規格の原本を手元に用意して参照されたい。

## 対象範囲

本書と本プログラムは、JIS C 9612:2013 の 3.12 に定める**回転数制御形ルームエアコン**だけを対象とする。
回転数制御形は、負荷に応じて圧縮機の回転数を一定の範囲で 3 段階以上または連続的に変えられる機種であり、通称インバータルームエアコンと呼ばれる。

次の機種は対象外とする。

- 定速単圧縮機形ルームエアコン (附属書 B の B.1.3.7)
- 回転数を 2 段階だけ切り替える機種、圧縮機を 2 台以上もつ機種。これらは定速単圧縮機形にも回転数制御形にも当たらず、附属書 B に計算方法がない。

計算する値は、冷房期間エネルギー消費効率 (CSPF)、暖房期間エネルギー消費効率 (HSPF)、通年エネルギー消費効率 (APF)と、その計算に用いる期間の空調負荷・消費電力量である。
外気温度の発生時間は、附属書 B に示された東京の値を用いる。特定地域の値を入力して計算することもできる ({doc}`02_usage`)。

次の事項は扱わない。

- 附属書 C (参考)の消費電力量の簡易算出方法、附属書 D (参考)のルームエアコンの選定方法
- 附属書 E、附属書 F のマルチ形ルームエアコンディショナ
- 規格本体の表示、性能の許容差、安全性能など、APF の計算以外の事項

## 本書の構成

本書は、次の章で構成する。

:::{container} symbols
1 章「はじめに」
: 本書の目的、準拠する規格、対象範囲、用語、記号と表記

: 本書の記号と附属書 B の記号の対応

: 例の機種について APF を試算し、APF がどの入力値と条件に左右されるかを分析した結果

## 用語

本書で用いる主な用語を次に示す。定義は JIS C 9612:2013 の箇条 3 と附属書 B の B.1.3、B.2.3、B.3.3 によるが、ここでは本書での意味を要約して示す。

### 能力と運転

:::{container} terms
定格冷房能力 (表示値)
: 機器に表示された定格の冷房能力。冷房・暖房の想定空調負荷の大きさを決めるのに用いる。

定格運転能力
: 能力試験と同じ圧縮機の回転数で運転したときの能力。

中間運転能力
: 定格能力 (表示値)の約 50 %の能力が出る圧縮機の回転数で運転したときの能力。

最大運転能力
: 暖房で、外気 2 ℃の条件で最大の能力が出る圧縮機の回転数で運転したときの能力。

最大モード
: 定格運転より高い回転数で、最大運転能力を出す運転。最大モードをもたない機種の扱いは 4 章による。

断続運転
: 負荷が中間運転能力より小さいとき、中間運転能力で運転と停止を繰り返して負荷に合わせる運転。

可変運転
: 負荷に合わせて能力を連続的に変える運転。冷房では中間運転能力と定格運転能力の間、暖房ではこれに加えて定格運転能力と最大運転能力の間で行う。

補助電熱装置
: 暖房で、能力の不足分を補う電熱装置。評価の計算に含める仮想的な熱源であり、実際の機器に備わっているかどうかによらない (4 章)。
:::

### 負荷と外気温度

:::{container} terms
想定空調負荷
: 各外気温度で冷房または暖房に必要と想定する熱量。外気温度の 1 次式で表す (想定冷房空調負荷、想定暖房空調負荷)。

温度区分
: 外気温度を 1 ℃ごとに区切った区分。区分ごとに運転状態と消費電力を求める。

発生時間
: 冷房期間または暖房期間に、各温度区分の外気温度が生じる時間。

交点温度
: 想定空調負荷と運転能力が等しくなる外気温度。可変運転のエネルギー消費効率の補間に用いる。

着霜領域
: 暖房で、室外側の熱交換器に霜が付き、能力が下がる外気温度の範囲 (−7 ℃を超え 5.5 ℃未満)。それ以外の範囲を無着霜領域という。
:::

### 効率と期間の値

:::{container} terms
エネルギー消費効率
: 能力を消費電力で割った値。冷房では EER、暖房では COP と書く。

部分負荷率
: 断続運転による効率の低下を表す値。連続運転したときの効率に対する比であり、1 以下となる。

期間総合空調負荷
: 冷房期間または暖房期間に処理する熱量の合計 (CSTL、HSTL)。暖房では補助電熱装置の熱量を含む。

期間消費電力量
: 冷房期間または暖房期間に消費する電力量の合計 (CSEC、HSEC)。暖房では補助電熱装置の消費電力量を含む。冷房と暖房の和を、単に期間消費電力量 (AEC)ともいう。

期間エネルギー消費効率
: 期間総合空調負荷を期間消費電力量で割った値 (CSPF、HSPF)。

通年エネルギー消費効率 (APF)
: 冷房期間と暖房期間の総合空調負荷の和を、期間消費電力量の和で割った値。
:::

## 記号と表記

記号は、附属書 B の記号をもとに、次のように書き分ける。記号の一覧と附属書 B の記号との対応は {doc}`05_symbols` に示す。

:::{container} symbols
添字 c、h
: 冷房期間の値には c、暖房期間の値には h を付ける (例: $\Phi_\mathrm{c,ful}(t)$、$\Phi_\mathrm{h,ful}(t)$)

添字 ful、haf、ext
: 定格運転、中間運転、最大運転を表す

添字 f
: 暖房の着霜時の値を表す (例: $\Phi_\mathrm{h,ful,f}(t)$)

EER、COP
: エネルギー消費効率。冷房は $\mathrm{EER}$、暖房は $\mathrm{COP}$ と書く

$t$、$t_j$
: 外気温度、温度区分 $j$ の外気温度
:::

単位は、能力・消費電力・空調負荷を W、期間の空調負荷・消費電力量を Wh、温度を ℃、時間を h とする。

式・図・表の番号は、章ごとに 1 から振る。附属書 B の式・表・条項を参照するときは、「附属書 B の式 (B.76)」のように附属書 B の番号で示す。
