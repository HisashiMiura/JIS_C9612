## 対象範囲

本書と本プログラムは、JIS C 9612:2013 の 3.12 に定める**回転数制御形ルームエアコン**だけを対象とする。
回転数制御形は、負荷に応じて圧縮機の回転数を一定の範囲で 3 段階以上または連続的に変えられる機種であり、通称インバータルームエアコンと呼ばれる。

次の機種は対象外とする。

- 定速単圧縮機形ルームエアコン (附属書 B の B.1.3.7)
- 回転数を 2 段階だけ切り替える機種、圧縮機を 2 台以上もつ機種。これらは定速単圧縮機形にも回転数制御形にも当たらず、附属書 B に計算方法がない。
