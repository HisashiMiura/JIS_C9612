# 試算例

本章では、本プログラムを用いて例の機種の APF を試算し、APF がどの入力値と条件に左右されるかを分析する。
試算は Jupyter Notebook `notes/case_studies.ipynb` で行った。本章の図と表は、この Notebook が出力したものである。

## 目的

APF は、冷房期間と暖房期間の多数の温度区分について、運転状態ごとに消費電力を求めて合計した値である ({doc}`03_method`)。
このため、ある入力値が APF にどの程度効くかは、計算式を見ただけでは分かりにくい。

本章の目的は、次の 4 点を試算によって明らかにすることである。

1. 期間の空調負荷と消費電力量が、どの運転状態で生じているか。
2. 試験値のうち、APF に大きく効く値はどれか。
3. 能力の規模と外気温度の分布が、APF にどう影響するか。
4. 最大モードをもたない機種の暫定の扱い ({ref}`r-h-nomax`) が、結果にどの程度影響するか。

## 方法

### 対象とする機種

定格冷房能力 (表示値) 2.8 kW の回転数制御形ルームエアコンを想定し、{numref}`tbl-cs-inputs` の試験値を与えた。
この値は説明用に設定したものであり、特定の機種の値ではない ({doc}`03_method` の図の例と同じ)。
定格運転のエネルギー消費効率を 4.0、中間運転を 5.0 とし、最大モードをもつ機種とした。

```{csv-table} 対象とする機種の試験値
:file: case_studies/tab_inputs.csv
:header-rows: 1
:name: tbl-cs-inputs
```

以下、この機種を東京の外気温度の発生時間 (附属書 B の表 B.3、表 B.6)で計算した場合を、基準ケースと呼ぶ。

### 検討ケース

基準ケースをもとに、次の 5 つのケースを検討した。

:::{container} terms
ケース 1: 基準ケースの内訳
: 基準ケースについて、運転状態ごとに発生時間、処理する空調負荷、消費電力量を集計し、期間全体に対する割合を求めた。

ケース 2: 入力値の感度分析
: 入力値 (試験値) を 1 つずつ基準ケースの値から −10 %、+10 % 変え、APF の変化率を求めた。中間運転能力を ±10 % 変えても、定格能力 (表示値) の 45 %〜55 % の範囲 (附属書 B の B.1.5.3.1、B.2.5.3.1) に収まる。

ケース 3: 能力の規模
: 定格冷房能力 (表示値) と試験値のすべてに同じ係数を掛け、定格冷房能力 2.2 kW、4.0 kW、5.6 kW の機種を作った。

ケース 4: 外気温度の分布
: 東京の外気温度の発生時間を、温度軸の方向に平行移動した。冷房期間は暑い側に 1〜3 ℃、暖房期間は寒い側に 2〜8 ℃ずらした。想定空調負荷の式は変えていない。特定地域の分布を簡易に模擬したものであり、実在の地域の値ではない。

ケース 5: 最大モードの有無
: 暖房の能力特性が基準ケースと同じで、最大モードをもたない機種を作り、基準ケースと比べた。最大モードをもたない機種の外気 2 ℃の着霜時の定格運転能力・消費電力には、基準ケースで係数から求まる値 (2 801.0 W、794.5 W) を与えた。外気温度の分布は、東京の値と、寒い側に 4 ℃、8 ℃ずらした値の 3 通りとした。
:::

### 評価の指標

ケース 2 では、入力値を変えたときの APF の変化率を次式で求めた。

$$
r = \frac{F'_\mathrm{AP}}{F_\mathrm{AP}} - 1
$$ (eq-cs-r)

:::{container} where
ここに、

$r$
: APF の変化率 (−)

$F'_\mathrm{AP}$
: 入力値を変えたときの通年エネルギー消費効率 (−)

$F_\mathrm{AP}$
: 基準ケースの通年エネルギー消費効率 (−)

である。
:::

冷房期間では、発生時間の 73.0 % が断続運転、27.0 % が可変運転であり、定格運転は生じなかった。
暖房期間では、発生時間の 77.4 % が断続運転、22.5 % が中間〜定格の可変運転であり、定格〜最大の可変運転は 0 ℃の温度区分 (2 h)だけで、最大運転は生じなかった。
空調負荷と消費電力量で見ても、断続運転と、中間運転に近い可変運転がほぼ全量を占めた。

## 考察

### 中間運転の性能が APF を左右する

ケース 1 のとおり、東京の分布では、期間の大部分で負荷が中間運転能力の付近にあり、機器は断続運転か、中間運転に近い可変運転をしている。
断続運転の消費電力は中間運転の消費電力から求まり ({doc}`03_method` の断続運転)、可変運転のエネルギー消費効率も、中間運転の交点温度での値が補間の一端となる。
このため、ケース 2 で中間運転の値が最も大きく効き、定格運転と最大運転の値はほとんど効かなかったと考えられる。

暖房の中間運転が冷房より大きく効いたのは、暖房期間の総合空調負荷が冷房期間の約 2 倍 (3 547 kWh と 1 749 kWh)あり、APF の分母・分子に占める割合が大きいためである。
APF を改善するには、定格条件の効率よりも、中間能力付近、特に暖房の中間運転の効率を高めることが有効である。

### APF は能力の規模によらない

ケース 3 で APF が規模によらなかったのは、想定空調負荷が定格冷房能力 (表示値)に比例し ({doc}`03_method` の想定冷房空調負荷・想定暖房空調負荷)、能力と消費電力もすべて同じ比率で変えたためである。
このとき、各温度区分の運転状態と、負荷に対する消費電力の比は変わらない。
したがって APF は、機器の規模ではなく、定格能力に対する各運転の能力の比と、各運転の効率で決まる指標である。
実際の機種で規模によって APF が異なるのは、これらの比や効率が規模によって異なるためである。

### 寒い地域では低温側の性能と最大モードの扱いが効く

ケース 4 では、暖房期間を寒い側にずらすと APF が大きく下がった。
寒い側では、想定暖房空調負荷が大きくなるうえ、着霜による能力・効率の低下が生じる温度区分の発生時間が増えるためである。
一方、冷房期間を暑い側にずらしても APF の低下は小さかった。冷房期間の空調負荷が暖房期間より小さく、APF に占める割合が小さいためである。

ケース 5 では、東京の分布で最大モードの有無がほとんど影響しなかったのに対し、寒い分布では HSPF に大きな差が生じた。
最大モードをもたない機種は、定格運転能力を超える負荷を補助電熱装置 (効率 1)で補うためである。
最大モードをもたない機種の扱いは附属書 B に規定がなく、本書の暫定の扱いである ({ref}`r-h-nomax`)。
東京の分布を用いる通常の評価では、この扱いが結果に与える影響は小さいが、特定地域の分布 (附属書 B の B.2.9)で寒い地域を評価する場合には影響が大きく、扱いを確定させる必要がある。

### 本試算の限界

本章の機種は説明用に設定したものであり、能力と効率の比は実在の機種と異なる可能性がある。
ケース 4 の分布は東京の分布を平行移動したものであり、実在の地域の分布の形を表すものではない。
したがって、本章の数値は傾向を示すものとして扱い、個別の機種や地域の評価には、その試験値と分布を用いて計算する必要がある。

## まとめ

例の機種について APF を試算し、次のことを確かめた。

1. 東京の分布では、期間の発生時間の 7〜8 割が断続運転であり、空調負荷と消費電力量のほぼすべてが、断続運転と中間運転に近い可変運転で生じる。
2. APF に最も大きく効く入力値は中間運転の消費電力と能力であり、特に暖房の中間運転は ±10 % の変化で APF を約 ±6 % 変える。定格運転と最大運転の値の影響は小さい。
3. すべての値を同じ比率で変えた場合、APF は能力の規模によらない。
4. 暖房期間の外気温度の分布が寒い側に移ると APF は大きく下がり、寒い分布では補助電熱装置の消費電力量が生じる。
5. 最大モードをもたない機種の暫定の扱いは、東京の分布ではほとんど影響しないが、寒い分布では HSPF を大きく変えるため、寒い地域の評価に用いる場合は扱いを確定させる必要がある。
