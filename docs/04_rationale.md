# 評価方法の根拠

本章では、{doc}`03_method` の計算方法のうち、JIS C 9612:2013 附属書 B (以下、附属書 B)の記述から解釈を要した事項と、附属書 B に明記がない事項について、採った方法とその理由を記録する。

記号は {doc}`03_method` と同じく、冷房は添字 c、暖房は添字 h を付けて書く。附属書 B の記述を引用する箇所でも、記号は本書の記号に置き換えている。

## 冷房期間

(r-c-coef)=
### 回転数制御形の外気 29 ℃の値

**採った方法**:外気 29 ℃での定格運転・中間運転の能力と消費電力を、常に外気 35 ℃の試験値に係数 (能力 1.077、消費電力 0.914)を掛けて求める。29 ℃の実測値は入力として受け付けない。

**理由**:附属書 B の表 B.1 では、回転数制御形の定格運転 (29 ℃)は試験項目に含まれず、中間運転 (29 ℃)は任意試験である。また、附属書 B の B.1.5.3.2 は、任意試験項目は試験を行わず係数を用いると定めている。

(r-c-min)=
### 最小運転能力

**採った方法**:最小運転能力・消費電力は、冷房期間の計算に用いない。

**理由**:附属書 B の表 B.1 には最小運転能力の試験条件と係数が示されているが、B.1.6 の計算式には現れない。また B.1.5.3.1 は、最小能力試験を行わないと定めている。

(r-c-cstl)=
### 冷房期間総合空調負荷の計算

**採った方法**:各温度区分の空調負荷 $Q_\mathrm{c}(t_j)$ を、想定冷房空調負荷と定格運転能力の小さいほう、すなわち $\min[L_\mathrm{c}(t_j),\ \Phi_\mathrm{c,ful}(t_j)]$ とする。

**理由**:附属書 B の式 (B.5)は、断続運転領域では $\Phi_\mathrm{c,ful}(t_j) = 0$、定格運転能力領域では $L_\mathrm{c}(t_j) = 0$ とおいて、2 つの和を足し合わせる形で書かれている。これは、上記の最小値をとることと同じである。冷房には補助熱源がないため、定格運転能力を超える負荷は処理されない。

## 暖房期間

(r-h-coef)=
### 係数で求める値

**採った方法**:次の値は、常に係数で求め、実測値は入力として受け付けない。

:::{container} symbols
外気 −7 ℃の値
: 定格運転・中間運転・最大運転の能力と消費電力

外気 2 ℃の着霜時の値
: 定格運転・中間運転の能力と消費電力。ただし、最大モードをもたない機種の定格運転の値は入力値とする

外気 2 ℃の無着霜時の値
: 最大運転の能力と消費電力
:::

**理由**:附属書 B の表 B.4 では、回転数制御形について、これらの値は任意試験とされているか、係数で計算しなければならないとされている。また、附属書 B の B.2.5.3.2〜B.2.5.3.4 は、任意試験項目は試験を行わず係数を用いると定めている。冷房期間と同じく、規格どおりの手順に限る ({ref}`r-c-coef`)。

(r-h-cop)=
### 無着霜領域の可変運転のエネルギー消費効率

**採った方法**:無着霜領域で中間運転能力と定格運転能力の間を可変運転するときの消費電力は、無着霜時のエネルギー消費効率 $C_\mathrm{OP,hf}(t_j)$ (附属書 B の式 (B.49))で求める。同じく、定格運転能力と最大運転能力の間を可変運転するときの消費電力は、無着霜時のエネルギー消費効率 $C_\mathrm{OP,fe}(t_j)$ (附属書 B の式 (B.50))で求める。

**理由**:附属書 B の B.2.6.5.5 a) 2) と a) 3) は無着霜領域の規定であるが、消費電力を着霜時のエネルギー消費効率 ($C_\mathrm{OP,hf,f}$、$C_\mathrm{OP,fe,f}$)で求めると書かれている。一方、同じ項で定義しているのは無着霜時の式 (B.49)、(B.50) であり、着霜時の式 (B.51)、(B.52) は b) の着霜領域で定義されている。このため、a) の記述は誤記とみなした。

(r-h-pext)=
### 着霜領域の最大運転の消費電力

**採った方法**:着霜領域で最大運転するときの消費電力は、着霜時の最大運転消費電力 $P_\mathrm{h,ext,f}(t_j)$ (附属書 B の式 (B.44))とする。

**理由**:附属書 B の B.2.6.5.5 b) 4) は、最大運転の消費電力を「式 (B.44) によって、$P_\mathrm{h,ext,f}(t_\mathrm{f})$ によって算出する」と書いている。交点温度 $t_\mathrm{f}$ での値は温度区分によらず一定となり、外気温度による消費電力の変化を表す式 (B.44) を指定している意味がなくなる。無着霜領域の最大運転 (a) 4))では、その温度区分での値 $P_\mathrm{h,ext}(t_j)$ を用いている。このため、$t_\mathrm{f}$ は $t_j$ の誤記とみなした。

(r-h-nomax)=
### 最大モードをもたない機種 (要確認)

**採った方法**:最大モードをもたない機種では、最大運転の能力・消費電力の特性に、定格運転の特性を用いる。すなわち、$\Phi_\mathrm{h,ext}(t) = \Phi_\mathrm{h,ful}(t)$、$P_\mathrm{h,ext}(t) = P_\mathrm{h,ful}(t)$、$\Phi_\mathrm{h,ext,f}(t) = \Phi_\mathrm{h,ful,f}(t)$、$P_\mathrm{h,ext,f}(t) = P_\mathrm{h,ful,f}(t)$ とする。このとき、定格〜最大の可変運転は生じず、定格運転能力を超える負荷は、定格運転能力で運転したうえで補助電熱装置で補う。外気 2 ℃の着霜時の定格運転能力・消費電力 $\Phi_\mathrm{h,ful,f}(2)$、$P_\mathrm{h,ful,f}(2)$ は入力値とする。

**理由**:附属書 B の表 B.4 注 a) は、最大モードをもたない機種 (最大運転時の圧縮機の回転数が定格運転時より高くならない機種)では、暖房低温能力試験で定格運転能力を測定する (必須試験)と定めているが、最大運転の特性をどう扱うかは書いていない。最大運転の能力が定格運転の能力を超えない機種なので、最大運転を定格運転と同じとみなした。

この扱いは規格に明記がないため、確認が必要である。

(r-h-extrap)=
### 交点温度が着霜領域・無着霜領域の外にある場合

**採った方法**:可変運転のエネルギー消費効率は、交点温度がその領域 (着霜領域または無着霜領域)の外にある場合も、附属書 B の補間式 (式 (B.49)〜(B.52))をそのまま用いて求める。補間の範囲の外では、直線を延長して求める (外挿)。

**理由**:附属書 B は、能力が連続で変化する場合のエネルギー消費効率を外気温度の 1 次式と仮定しており、交点温度の範囲や領域による制限を設けていない。例えば {doc}`03_method` の例では、着霜時の中間運転の交点温度 $t_\mathrm{e}$ は 7.76 ℃であり、着霜領域 (5.5 ℃未満)の外にある。

## 共通事項

(r-intersection)=
### 交点温度の求め方

**採った方法**:交点温度は、負荷線と能力線の関係を外気温度について解いた式 ({doc}`03_method` の冷房期間・暖房期間の「交点温度」)で求める。冷房では附属書 B の式 (B.20)、(B.22)、暖房では式 (B.60)〜(B.71) と同じ値を与える。試験値の係数を代入して整理した式 (冷房の式 (B.23)〜(B.26)、暖房の式 (B.72)〜(B.75))は用いない。

**理由**:係数を代入して整理した式は、代入前の式と同じ値を与える。試験値を先に係数で求め、代入前の形の式で交点温度を求めれば、試験値を補完する式と交点温度を求める式を分けて確認できる。

(r-region)=
### 運転状態の判定

**採った方法**:各温度区分の運転状態は、その温度での空調負荷と能力を直接比べて判定する。交点温度は、可変運転域の効率の補間にだけ用いる。2 直線が平行で交点が求まらない場合は、エラーとして計算を止める。

**理由**:附属書 B は運転状態の条件を、負荷と能力の大小関係 (例:$L_\mathrm{c}(t_j) \le \Phi_\mathrm{c,haf}(t_j)$)で定めている。交点温度から温度区分の境界を逆算すると、交点が温度区分の範囲外にある場合の扱いが別に必要になる。
