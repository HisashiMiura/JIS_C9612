# 評価方法の根拠

本章では、{doc}`03_method` の計算方法のうち、JIS C 9612:2013 附属書 B (以下、附属書 B)の記述から解釈を要した事項と、附属書 B に明記がない事項について、採った方法とその理由を記録する。

## 冷房期間

(r-c-coef)=
### 回転数制御形の外気 29 ℃の値

**採った方法**:外気 29 ℃での定格運転・中間運転の能力と消費電力を、常に外気 35 ℃の試験値に係数 (能力 1.077、消費電力 0.914)を掛けて求める。29 ℃の実測値は入力として受け付けない。

**理由**:附属書 B の表 B.1 では、回転数制御形の定格運転 (29 ℃)は試験項目に含まれず、中間運転 (29 ℃)は任意試験である。また、附属書 B の B.1.5.3.2 は、任意試験項目は試験を行わず係数を用いると定めている。

(r-c-min)=
### 最小運転能力

**採った方法**:最小運転能力・消費電力は、冷房期間の計算に用いない。

**理由**:附属書 B の表 B.1 には最小運転能力の試験条件と係数が示されているが、B.1.6 の計算式には現れない。また B.1.5.3.1 は、最小能力試験を行わないと定めている。

(r-c-cstl)=
### 冷房期間総合空調負荷の計算

**採った方法**:各温度区分の空調負荷 $L(t_j)$ を、想定冷房空調負荷と定格運転能力の小さいほう、すなわち $\min[L_\mathrm{c}(t_j),\ \Phi_\mathrm{ful}(t_j)]$ とする。

**理由**:附属書 B の式 (B.5)は、断続運転領域では $\Phi_\mathrm{ful}(t_j) = 0$、定格運転能力領域では $L_\mathrm{c}(t_j) = 0$ とおいて、2 つの和を足し合わせる形で書かれている。これは、上記の最小値をとることと同じである。冷房には補助熱源がないため、定格運転能力を超える負荷は処理されない。

## 共通事項

(r-intersection)=
### 交点温度の求め方

**採った方法**:交点温度は、附属書 B の式 (B.20)、(B.22) と同じ式 ({doc}`03_method` の「交点温度」)で求める。附属書 B の式 (B.25)、(B.26) は用いない。

**理由**:附属書 B の式 (B.25)、(B.26) は、式 (B.20)、(B.22) に 29 ℃の係数 1.077 を代入して整理した式であり、同じ値を与える。29 ℃の値を係数で求めたうえで式 (B.20)、(B.22) を用いれば、29 ℃の値を求める式と交点温度を求める式を分けて確認できる。

(r-region)=
### 運転状態の判定

**採った方法**:各温度区分の運転状態は、その温度での空調負荷と能力を直接比べて判定する。交点温度は、可変運転域の効率の補間にだけ用いる。2 直線が平行で交点が求まらない場合は、エラーとして計算を止める。

**理由**:附属書 B は運転状態の条件を、負荷と能力の大小関係 (例:$L_\mathrm{c}(t_j) \le \Phi_\mathrm{haf}(t_j)$)で定めている。交点温度から温度区分の境界を逆算すると、交点が温度区分の範囲外にある場合の扱いが別に必要になる。
